# اكتشف وطنك مع الإمام عاصم

لعبة أسئلة جماعية لليوم الوطني السعودي: لوحة فئات، فريقان على جهاز واحد،
ووسائل مساعدة. بنك الأسئلة **جاهز** وكله عن الوطن: التوحيد، الرموز، الجغرافيا، الملوك، ولي العهد، الرؤية، التراث، الشعارات، المأكولات، الشمال، والجنوب.

**العب الآن:** <https://rajaxdx.github.io/watani/>

**التشغيل محلياً:** افتح `index.html` مباشرة، أو عبر سيرفر محلي:

```bash
python -m http.server 8215 --bind 127.0.0.1
```

بلا مكتبات ولا خطوة بناء ولا إنترنت — كل شي يشتغل على الجهاز.

---

## القواعد

1. اكتبوا أسماء الفريقين، وكل فريق يختار **٣ وسائل مساعدة** من خمس.
2. اللوحة **٦ فئات × ٣ مستويات**: ١٠٠ سهل · ٢٥٠ متوسط · ٤٠٠ صعب.
3. القرعة تختار من يبدأ. الفريق صاحب الدور يختار خانة، وأحدكم يقرأ السؤال.
4. بعد الإجابة: **عرض الإجابة**، ثم النقاط للفريق المستحق أو **بدون نقاط**.
5. الدور ينتقل تلقائياً، واللي يجمع نقاط أكثر بعد **١٨ سؤالاً** يكسب.

في نافذة السؤال عدّاد اختياري ٦٠ ثانية، و`Esc` يقفل النافذة.

## وسائل المساعدة

| الوسيلة | الأثر |
|---|---|
| 🪤 الفخ | إذا أجاب الفريق الآخر صحيحاً، تذهب النقاط لصاحب الفخ |
| ✋ استريح | تخطّي السؤال بلا نقاط، والدور يبقى مع الفريق نفسه |
| 🕳️ الحفرة | يُمنع الفريق الآخر من أخذ نقاط هذا السؤال |
| 📞 اتصال بصديق | ٣٠ ثانية بعدّاد داخل نافذة السؤال |
| ✌️ جاوب جوابين | إجابتان، وتُحتسب إن صحّت إحداهما |

كل وسيلة تُستخدم **مرة واحدة** طوال اللعبة، وتُفعَّل بعد فتح السؤال بالضغط على
أيقونتها في بطاقة الفريق.

## بنك الأسئلة

`js/questions.js` — **١١ فئة و١٦٠ سؤالاً** جاهزة (١٥ لكل فئة — ٥ لكل مستوى، والشعارات ١٠)،
وتقدر تزيد عليها من لوحة الإدارة.

| الفئة | المحتوى |
|---|---|
| 🏛️ التوحيد والتأسيس | ٢٣ سبتمبر، فتح الرياض، الدولتان الأولى والثانية |
| 🟩 رموز الوطن | العلم، الشعار، النشيد، يوم العلم |
| 🏜️ جغرافيا المملكة | المناطق، الربع الخالي، السودة، مواقع اليونسكو |
| 👑 ملوك وقادة | الملوك السبعة وترتيبهم وألقابهم |
| 🤴 محمد بن سلمان | المناصب وتواريخها، مسك، صندوق الاستثمارات، السعودية الخضراء، ذا لاين |
| 🚀 رؤية ٢٠٣٠ وإنجازات | الرؤية، نيوم، الفضاء، ٢٠٣٤ |
| 🎶 تراث | العرضة، السدو، القهوة، المصمك، الجنادرية |
| 🏷️ الشعارات | «لمن هذا الشعار؟» بالصورة: السعودية، سار، نيوم، موهبة، الجوازات… |
| 🍲 المأكولات | الكبسة، الكليجا، الجريش، المعصوب، المندي، الحنيذ، المغش، الصيادية، العريكة |
| 🏔️ الشمال | تبوك والجوف وحائل والحدود الشمالية: جبل اللوز، قلعة مارد، أجا وسلمى، الرجاجيل |
| 🌿 الجنوب | عسير وجازان ونجران والباحة: رجال ألمع، البن الخولاني، ذي عين، الأخدود |

كل خانة تسحب سؤالاً **عشوائياً** من مستواها، فالجولة تختلف كل مرة تلعبونها.
واللوحة تتسع لست فئات، فشاشة الفئات تختار لك **الأكمل أسئلةً** وتتجاهل الفاضية
(الشعارات أقل أسئلةً فما تنختار تلقائياً — اخترها بنفسك من شاشة الفئات).

## لوحة الإدارة

زر ⚙️ في أعلى الترويسة يفتح **بنك الأسئلة** بأربعة تبويبات:

| التبويب | وش يسوي |
|---|---|
| 📝 الأسئلة | إضافة وتعديل وحذف — تختار الفئة والمستوى وتشوف قائمتها |
| 📂 الفئات | إضافة فئة بإيموجي واسم، أو حذف فئة بكل أسئلتها |
| 🏆 النقاط | تغيير ١٠٠/٢٥٠/٤٠٠ — ينطبق على اللوحة فوراً |
| 💾 نسخة احتياطية | تصدير واستيراد JSON · استعادة الأصل · مسح الكل |

**بلا كلمة مرور بقرار صريح:** اللعبة محلية والبيانات في متصفح هذا الجهاز وحده،
فكلمة المرور كانت ستمنع صاحب الجهاز من بياناته هو ولا تمنع أحداً غيره من شيء.

### أين تُحفظ التعديلات

في `localStorage` بمفاتيح `nd_categories` و`nd_bank` و`nd_points` — ما تمسّ
ملف `js/questions.js` أبداً. زر **«رجّع أسئلة اليوم الوطني الأصلية»** يمسح
تعديلاتك ويرجّع الفئات والأسئلة كما جت مع اللعبة.

**فئة أصلية جديدة تصل للبنوك المحفوظة تلقائياً.** البنك المحفوظ يتقدّم على
الأصل، فبدون دمج ما كان أحد عنده تعديلات بيشوف فئة مضافة لاحقاً. كل فئة أصلية
لم تمرّ على المتصفح تُدمج **مرة واحدة** (`nd_seen_defaults`) — فلو حذفتها بعدها
ما ترجع. ولو كنت أنشأت فئة بنفس الموضوع (مثل «الأمير محمد بن سلمان») تتعبّى
فئتك بأسئلة الأصل بدل ما تتكرر.

صدّر نسخة JSON قبل ما تمسح بيانات المتصفح، أو عشان تنقل بنكك لجهاز ثاني.

### إضافة أسئلة من الملف

تقدر بدل اللوحة تعدّل `js/questions.js` مباشرة (يغيّر الأصل نفسه):

```js
{ emoji: '🏛️', q: 'نص السؤال؟', a: 'الإجابة' },
// بصورة: ملف داخل assets/ (img للسؤال، aImg للإجابة)
{ emoji: '🏷️', img: 'assets/logos/neom.jpg', q: 'لمن هذا الشعار؟', a: 'نيوم' },
```

الفئة الجديدة تحتاج سطراً في `DEFAULT_CATEGORIES` ومفتاحاً بنفس `id` داخل
`DEFAULT_QBANK` فيه `easy` و`medium` و`hard`. لاحظ إن تعديلات اللوحة المحفوظة
تتقدّم على الملف — اضغط «رجّع الأسئلة الأصلية» عشان تشوف تغييرك.

## البنية

```
index.html        الشاشات كلها (رئيسية · إعداد · فئات · لوحة · نهاية · عن اللعبة · إدارة · نوافذ)
css/style.css     الهوية: ليل أخضر وذهب وسدو + أخضر العلم
js/questions.js   البنك الأصلي: DEFAULT_CATEGORIES و DEFAULT_QBANK — لا منطق فيه
js/game.js        المنطق والعرض والأصوات والتخزين (Web Audio بلا ملفات صوت)
js/admin.js       لوحة بنك الأسئلة — تعتمد على أدوات game.js ولا تُستدعى منه
js/about.js       شاشة «عن اللعبة» — تُبنى من QBANK وCATEGORIES، وتُحمَّل بعد game.js
assets/emblem.svg شعار المملكة الرسمي
assets/logos/     صور فئة الشعارات (سهل · متوسط · صعب)
```

شعار المملكة في الترويسة ملف SVG متّجه (`assets/emblem.svg`) يبقى حادّاً على أي
شاشة. الصور النقطية الوحيدة هي شعارات الجهات في `assets/logos/`، تُعرض بخلفية
بيضاء حتى لا تختفي الشفافة منها على الخلفية الداكنة.

بعد أي تعديل على CSS/JS ارفع `?v=` في `index.html` حتى تصل النسخة الجديدة
للمتصفحات بدون تحديث قسري.
